Path / Directory Traversal

HIGH SEVERITY Unauthorized Access (CWE-22) Signature Pattern Matching 0 Detections Recorded
🛡️ Attack Overview

Path traversal attacks use directory navigation sequences (../ or ..\) to manipulate file paths and access restricted directories and sensitive system files outside the web root directory.

⚙️ How It Works (Adversary Mechanics)

When a web application takes filename input without canonical path validation, the attacker traverses upward out of the document root to access files such as /etc/passwd, /etc/shadow, or Windows boot.ini.

🔄 Attack Progression Flow
Attacker ──[ GET /view?file=../../../../etc/passwd ]──> Web Server ──[ IDS Payload Inspection ]──> Traversal Sequence Detected ──[ Request Dropped & Source IP Blocked ]
🔬 Actual IDS Detection Implementation

SignatureDetector evaluates regex r'(?:\.\./|\.\.\\|%2e%2e%2f|/etc/passwd|win\.ini)' on all incoming packet payloads. Instant 1-packet detection.

🚨 Impact & Defensive Mitigation
Security Impact:

Disclosure of server credentials, SSH keys, source code, configuration files, and OS user lists.

Defensive Mitigation & Firewall Rule:

Use path canonicalization (os.path.realpath) and verify prefixes, avoid passing user input directly into filesystem APIs, and enforce IDS firewall rules.
