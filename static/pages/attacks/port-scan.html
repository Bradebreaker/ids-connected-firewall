Port Scan Reconnaissance

MEDIUM SEVERITY Reconnaissance (TA0043) Behavioral Analysis (Sliding Window) 0 Detections Recorded
🛡️ Attack Overview

A port scan is an adversarial network reconnaissance technique where an attacker systematically sends probe packets across a broad spectrum of TCP and UDP ports on a target host to identify open listening services, daemon versions, and potential vulnerabilities.

⚙️ How It Works (Adversary Mechanics)

The attacker tools (e.g. Nmap, Masscan, ZMap) send TCP SYN packets, Connect requests, or UDP datagrams to sequential or randomized port numbers. By evaluating whether the server responds with SYN-ACK (open), RST (closed), or ICMP Port Unreachable, the attacker maps the perimeter defense.

🔄 Attack Progression Flow
Attacker Machine ──[ TCP SYN probes to ports 21, 22, 80, 443, 3306... ]──> Network Boundary ──[ Distinct Port Count Tracked in Sliding Window ]──> Threshold Reached (≥15 ports) ──[ IDS Triggered & IP Quarantined ]
🔬 Actual IDS Detection Implementation

The PortScanDetector tracks unique destination ports targeted by each external source IP using an in-memory sliding time window (collections.deque). When the count of unique destination ports reaches or exceeds the configured threshold within the sliding window, an alert is triggered. No AI is used; this is an exact stateful sliding-window algorithm.

System Configuration & Thresholds:
PORT_SCAN_WINDOW_SECONDS = 60s, PORT_SCAN_THRESHOLD = 15 distinct ports

🚨 Impact & Defensive Mitigation
Security Impact:

Confidentiality breach regarding internal network topology, active service discovery, OS fingerprinting, and preparation for targeted service exploitation.

Defensive Mitigation & Firewall Rule:

Automated quarantine via iptables (DROP) on Linux hosts or Windows firewall rule addition. Offending source IP is isolated for 3,600s TTL. Whitelisted management IPs are preserved.
