Brute Force Authentication

MEDIUM SEVERITY Credential Access (TA0006) Behavioral Rate Analysis 0 Detections Recorded
🛡️ Attack Overview

Brute force attacks involve automated scripts repeatedly submitting credential guesses or initiating rapid connection handshakes against authentication services (SSH, FTP, Telnet, RDP, MySQL) to achieve unauthorized administrative access.

⚙️ How It Works (Adversary Mechanics)

The adversary automates password dictionary attacks or credential stuffing against sensitive ports. The client issues rapid TCP connection handshakes followed by authentication payload submission until valid credentials match or the connection is blocked.

🔄 Attack Progression Flow
Attacker Script ──[ Rapid TCP connections to port 22/21/3389 ]──> Sensitive Port Filter ──[ Connection Rate Tracked per Source IP ]──> Exceeds 10 attempts in 30s ──[ Quarantine Enforced ]
🔬 Actual IDS Detection Implementation

The BruteForceDetector isolates packets targeting BRUTE_FORCE_PORTS and maintains a sliding timestamp deque for each source IP. If the number of connection attempts exceeds BRUTE_FORCE_THRESHOLD within BRUTE_FORCE_WINDOW_SECONDS, an alert is triggered. Pure stateful connection tracking.

System Configuration & Thresholds:
BRUTE_FORCE_WINDOW_SECONDS = 30s, BRUTE_FORCE_THRESHOLD = 10 attempts, PORTS = [21, 22, 23, 3389, 3306, 5432]
📡 Network Traffic Example & Safe Payload
Raw Packet / Protocol Dump:
203.0.113.45:51230 -> 192.168.1.10:22 TCP [SYN] Seq=0 Win=64240 203.0.113.45:51231 -> 192.168.1.10:22 TCP [SYN] Seq=0 Win=64240 203.0.113.45:51232 -> 192.168.1.10:22 TCP [SYN] Seq=0 Win=64240 [... repeated 10+ times within 30 seconds ...]
Benign Verification Payload:
Repeated benign SYN handshakes directed towards port 22 or 21 without actual credential exploitation.
🚨 Impact & Defensive Mitigation
Security Impact:

Account compromise, unauthorized shell access, privilege escalation, and service denial through account lockouts.

Defensive Mitigation & Firewall Rule:

Automated firewall quarantine via iptables DROP. Rate limiting on authentication daemons (fail2ban), public key authentication enforcement, and disabling root SSH logins.
