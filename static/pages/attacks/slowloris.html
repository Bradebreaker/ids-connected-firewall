Slowloris Low-and-Slow DoS

MEDIUM SEVERITY Denial of Service (TA0040) Connection State & Rate Analysis 0 Detections Recorded
🛡️ Attack Overview

Slowloris is a low-bandwidth Denial of Service attack that operates by opening multiple connections to the target web server and keeping them open as long as possible by periodically sending incomplete HTTP headers.

⚙️ How It Works (Adversary Mechanics)

The attacker sends partial HTTP GET requests without the terminating double CRLF (\r\n\r\n). Periodically, the attacker transmits keep-alive header fragments (e.g. X-a: b\r\n). The server keeps worker threads open waiting for the request to finish until thread pool exhaustion occurs.

🔄 Attack Progression Flow
Attacker ──[ Opens 100+ TCP connections ]──> Web Server ──[ Incomplete headers: 'X-a: b\r\n' sent every 5s ]──> Server Worker Threads Starved ──[ IDS Flood/Slowloris Detector Triggers ]──> Offending IP Blocked
🔬 Actual IDS Detection Implementation

The FloodDetector tracks connection state and identifies partial HTTP header requests (presence of 'X-a: b\r\n' without double CRLF termination) combined with high concurrent socket counts per source IP.

System Configuration & Thresholds:
FloodDetector Rule: 'Slowloris Partial Header Pattern', Category: slowloris, Severity: MEDIUM

🚨 Impact & Defensive Mitigation
Security Impact:

Web server thread exhaustion, starvation of legitimate clients, service unavailability despite minimal attacker bandwidth.

Defensive Mitigation & Firewall Rule:

Configure minimum incoming data rates (e.g. Nginx client_body_timeout and client_header_timeout), use reverse proxies with asynchronous event loops, and enforce automated firewall drops.
